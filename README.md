Минимальный Metamod:Source плагин для CS2, вырезанный из большого античита cs2ac-legacy. Единственная функция — банить игроков, которые слишком часто меняют видимый ник (типичный признак обхода бана/спама). Никакого детекта читов, вебхуков, апдейтера или "рекламного" watermark'а — только эта одна фича.
